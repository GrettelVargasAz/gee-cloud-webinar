Script 01 — Conociendo el Code Editor

Primer acercamiento al entorno de Google Earth Engine y a los fundamentos mínimos de JavaScript que se utilizarán durante el webinar.

Duración estimada: 30 minutos Nivel: introductorio Autora: Grettel Vargas Azofeifa

🎯 Objetivos

  1. Reconocer los paneles principales del Code Editor.
  2. Ejecutar instrucciones y consultar la Console.
  3. Crear variables, arreglos y objetos de parámetros.
  4. Crear una geometría y representarla en el mapa.
  5. Centrar el mapa, cambiar el mapa base y utilizar Inspector y Layers.
Conceptos: Code Editor, Scripts, Docs, Assets, Console, Inspector, Layers, Tasks, var, arreglos, objetos, print(), ee.Geometry.Point() y Map.

📖 Cómo usar esta guía

  1. Abra el Code Editor de Google Earth Engine.
  2. Copie y ejecute cada bloque en el orden presentado.
  3. Pulse Run después de cada paso.
  4. Observe la Console y el mapa.
  5. Complete cada práctica antes de continuar.

1. Reconocer el entorno

Panel izquierdo

  • Scripts: código guardado.
  • Docs: documentación.
  • Assets: datos propios o institucionales.

Área central

  • Editor: espacio para escribir código.
  • Mapa: visualización de resultados.

Panel derecho

  • Inspector: consulta de objetos, capas y píxeles.
  • Console: resultados de print().
  • Tasks: tareas de exportación.

2. Mostrar información en la Console

print() permite mostrar mensajes y objetos en la pestaña Console.

JavaScript
print('¡Bienvenidos al webinar!');
print('Primer script ejecutado correctamente.');
print('Estoy aprendiendo Google Earth Engine.');
🧪 Práctica: cambie el último mensaje, pulse Run y revise el resultado en la Console.

3. Crear variables

Una variable guarda un valor que puede reutilizarse. En esta guía introductoria se emplea var.

JavaScript
var pais = 'Costa Rica';
var anio = 2026;
var nubosidadMaxima = 20;
var cursoPosterior = 'SEPAL';

print('País:', pais);
print('Año:', anio);
print('Nubosidad máxima:', nubosidadMaxima);
print('Continuidad de la capacitación:', cursoPosterior);
🧪 Práctica: cambie el país o el porcentaje máximo de nubosidad y ejecute nuevamente.

4. Crear un arreglo de bandas

Un arreglo de JavaScript contiene varios valores ordenados. Para una composición de color natural de Sentinel-2 se utilizan B4 (rojo), B3 (verde) y B2 (azul).

JavaScript
var bandasColorNatural = [
  'B4',
  'B3',
  'B2'
];

print('Bandas de color natural:', bandasColorNatural);
print('Primera banda:', bandasColorNatural[0]);
🧪 Práctica: consulte en la Console la segunda banda utilizando bandasColorNatural[1].

5. Crear un objeto de parámetros

Un objeto organiza pares propiedad: valor. Más adelante este tipo de estructura se utilizará para configurar la visualización de imágenes.

JavaScript
var visualizacion = {
  bands: bandasColorNatural,
  min: 0,
  max: 3000
};

print('Parámetros de visualización:', visualizacion);
print('Valor máximo:', visualizacion.max);
🧪 Práctica: cambie max de 3000 a 2500 y revise el objeto en la Console.

6. Crear una geometría

ee.Geometry.Point() crea un punto. Las coordenadas se escriben en el orden longitud, latitud.

JavaScript
var puntoSanJose = ee.Geometry.Point([
  -84.10,
  9.93
]);

print('Punto de referencia:', puntoSanJose);
Importante: en este ejemplo, -84.10 es la longitud y 9.93 es la latitud.

7. Centrar el mapa

Map.centerObject() centra el mapa sobre el objeto creado. El segundo argumento corresponde al nivel de zoom.

JavaScript
Map.centerObject(
  puntoSanJose,
  9
);
🧪 Práctica: cambie el zoom de 9 a 7 y observe la diferencia.

8. Agregar la geometría al mapa

Map.addLayer() agrega el punto como una capa visible.

JavaScript
Map.addLayer(
  puntoSanJose,
  {{color: 'red'}},
  'San José'
);
🧪 Práctica: cambie el color de 'red' a 'blue' y vuelva a ejecutar el script.

9. Cambiar el mapa base

Map.setOptions() permite cambiar el fondo cartográfico.

JavaScript
Map.setOptions('HYBRID');
🧪 Práctica: pruebe 'ROADMAP', 'TERRAIN' y 'HYBRID'.

10. Utilizar Inspector y Layers

  1. Abra la pestaña Inspector.
  2. Haga clic cerca del punto.
  3. Observe las coordenadas y la información disponible.
  4. En Layers, active y desactive la capa San José.
En el Script 02 se agregarán capas geográficas con atributos y límites administrativos.

🚀 Desafío opcional

Cree un punto sobre otra ciudad de Centroamérica, cambie el nombre de la variable, el nivel de zoom y el color.

Ejemplo: Ciudad de Guatemala
var ciudadGuatemala = ee.Geometry.Point([
  -90.5069,
  14.6349
]);

Map.centerObject(
  ciudadGuatemala,
  9
);

Map.addLayer(
  ciudadGuatemala,
  {{color: 'blue'}},
  'Ciudad de Guatemala'
);

✅ Resumen

  • Reconocimos los paneles del Code Editor.
  • Ejecutamos instrucciones y utilizamos print().
  • Creamos variables, un arreglo y un objeto.
  • Creamos una geometría y la agregamos al mapa.
  • Centramos el mapa y cambiamos el mapa base.
  • Utilizamos Inspector y Layers.
