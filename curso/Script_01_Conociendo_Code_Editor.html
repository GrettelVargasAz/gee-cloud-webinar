Script 01 — Conociendo el Code Editor

Primer acercamiento al entorno de Google Earth Engine y a los fundamentos mínimos de JavaScript que se utilizarán durante el webinar.

Duración estimada: 30 minutosNivel: introductorioAutora: Grettel Vargas Azofeifa

🎯 Objetivos

  1. Reconocer los paneles principales del Code Editor.
  2. Ejecutar instrucciones y consultar la Console.
  3. Crear variables, listas y objetos de parámetros.
  4. Centrar el mapa y cambiar el mapa base.
Conceptos: Code Editor, Scripts, Docs, Assets, Console, Inspector, Layers, Tasks, var, listas, objetos, print() y Map.

📖 Cómo usar esta guía

  • Ejecute el script con Run.
  • Observe la pestaña Console después de cada paso.
  • Realice las prácticas cortas antes de continuar.
  • No es necesario memorizar las instrucciones.

1. Reconocer el entorno

Panel izquierdo

  • Scripts: código guardado.
  • Docs: documentación de objetos y funciones.
  • Assets: datos propios o institucionales.

Área central

  • Editor: espacio para escribir código.
  • Mapa: visualización de resultados.

Panel derecho

  • Inspector: consulta de capas, objetos y píxeles.
  • Console: resultados de print().
  • Tasks: tareas de exportación.

2. Mostrar información en la Console

print() muestra mensajes u objetos en la pestaña Console.

JavaScript
print('¡Bienvenidos al webinar!');
print('Primer script ejecutado correctamente.');

print('Estoy aprendiendo Google Earth Engine.');
🧪 Práctica: cambie el último mensaje y ejecute nuevamente el script.

3. Crear variables

Una variable guarda un valor que puede reutilizarse. En estos ejemplos introductorios se utiliza la palabra var.

JavaScript
var pais = 'Costa Rica';
var anio = 2026;
var nubosidadMaxima = 20;
var cursoPosterior = 'SEPAL';

print('País:', pais);
print('Año:', anio);
print('Nubosidad máxima:', nubosidadMaxima);
print('Continuidad de la capacitación:', cursoPosterior);
🧪 Práctica: cambie el país o el porcentaje máximo de nubosidad.

4. Crear una lista

Una lista contiene varios valores ordenados. Más adelante se utilizarán listas para seleccionar bandas.

JavaScript
var bandasColorNatural = [
  'B4',
  'B3',
  'B8'
];

print('Bandas de color natural:', bandasColorNatural);
print('Primera banda:', bandasColorNatural[0]);
🧪 Práctica: agregue 'B8' al final de la lista y revise la Console.

5. Crear un objeto de parámetros

Un objeto organiza pares propiedad: valor. Se utilizará para configurar visualizaciones y exportaciones.

JavaScript
var visualizacion = {
  bands: bandasColorNatural,
  min: 0,
  max: 3000
};

print('Parámetros de visualización:', visualizacion);
print('Valor máximo:', visualizacion.max);
🧪 Práctica: cambie max de 3000 a 2500.

6. Centrar el mapa

Map.setCenter(longitud, latitud, zoom) centra el mapa en unas coordenadas y define el nivel de acercamiento.

JavaScript
Map.setCenter(
  -84.10,
  9.93,
  9
);
🧪 Práctica: cambie el nivel de zoom de 7 a 5 o 9.

7. Cambiar el mapa base

Map.setOptions() permite cambiar el fondo cartográfico.

JavaScript
Map.setOptions('HYBRID');
🧪 Práctica: pruebe 'ROADMAP', 'TERRAIN' o 'HYBRID'.

8. Utilizar Inspector y Layers

  1. Abra Inspector.
  2. Haga clic en el mapa.
  3. Observe las coordenadas.
  4. Revise Layers.
En el Script 02 se agregarán las primeras capas temáticas.

🚀 Desafío opcional

Busque en la documentación Map.setCenter() y centre el mapa sobre otro país de Centroamérica.

Ejemplo: Ciudad de Guatemala
Map.setCenter(
  -90.5069,
  14.6349,
  9
);

  • Creamos variables, listas y objetos.
  • Centramos el mapa.
  • Cambiamos el mapa base.
