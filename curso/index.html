Curso introductorio

Google Earth Engine para Aplicaciones Agroambientales

Guía práctica para conocer el Code Editor, trabajar con datos geográficos, explorar imágenes satelitales, calcular índices espectrales y exportar resultados.

Comenzar con el Script 01 Descargar Script 01

Contenido del curso

Los scripts están organizados de forma progresiva. Cada guía incluye objetivos, explicaciones breves, código, prácticas y un desafío opcional.

Script 01 — Conociendo el Code Editor

Paneles principales, Console, variables, listas, objetos, centrado del mapa y mapas base.

Abrir

Script 02 — Datos geográficos

Geometrías, colecciones de elementos, filtros, límites administrativos y operaciones espaciales.

Próximamente

Script 03 — Exploración de imágenes satelitales

Sentinel-2, Landsat 8, filtros, composiciones, bandas espectrales y visualización.

Próximamente

Script 04 — Índices espectrales

Cálculo e interpretación de NDVI, NDWI y NDMI para aplicaciones agroambientales.

Próximamente

Script 05 — Exportación de resultados

Exportación de imágenes y tablas para Google Drive, QGIS y otros sistemas de información geográfica.
